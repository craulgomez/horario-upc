# Política de Seguridad - HorarioUPC

## Versiones con Soporte

Actualmente, solo la versión principal en la rama `main` recibe parches de seguridad y correcciones activas.

| Versión | Soportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportar una Vulnerabilidad

Si descubres una posible vulnerabilidad de seguridad en **HorarioUPC**, te pedimos encarecidamente que no la publiques en issues abiertos ni foros públicos.

Por favor, sigue estos pasos para reportarla de forma responsable:

1. Envía un correo electrónico a los mantenedores principales del repositorio o crea un **Security Advisory Privado** directamente en la pestaña "Security" de GitHub.
2. Incluye en el reporte:
   - Tipo de problema (ej. inyección SQL, bypass de autenticación JWT, XSS, etc.).
   - Pasos detallados para reproducir el fallo o código de prueba de concepto (PoC).
   - Componente afectado (Backend Spring Boot, Frontend React, Base de Datos).
   - Posible impacto estimado.
3. El equipo acusará recibo en un plazo no mayor a 48 horas y trabajará en una solución confidencial antes de publicar cualquier aviso público.

¡Agradecemos tu colaboración para mantener seguros a los estudiantes y usuarios de HorarioUPC!
